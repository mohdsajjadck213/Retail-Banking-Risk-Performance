# Retail-Banking-Risk-Performance
Retail Banking Portfolio Risk & Performance Assessment using Python, SQL, and Power BI.

## Project Overview
This project analyzes retail banking portfolio performance, borrower risk behavior, branch-level trends, transaction quality, and default-related factors using a mix of Python notebooks, SQL queries, and Power BI reporting.

## Portfolio Contents
- [Python notebooks](python/)
- [SQL scripts](sql/)
- [Power BI dashboard](powerbi/)
- [Project documentation](documentation/)

## Key Analysis Areas
- Loan portfolio health
- Customer risk assessment
- Branch performance evaluation
- Transaction integrity and irregularity analysis
- Default factors and borrower risk profiling

## Tools Used
- Python
- SQL
- Power BI
- Jupyter Notebook
